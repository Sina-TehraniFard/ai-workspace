# 文書の書き方

設計判断の一覧、実装計画書、ai-docs の記録はこのルールで書く。書き終えたら、このルールに照らして読み直してから出す。

1. 決まったことだけを書く。誰に言われたか、どの会話で決まったかといった経緯は書かない
2. 1つの事柄は1回だけ書く。同じ内容を、表と文章や、肯定と否定の両方の形で繰り返さない
3. 前の文をまとめ直す文を足さない。「つまり」「要するに」で始めたくなったら、どちらか一方の文を残す
4. 括弧は補足のためだけに使う。直前の語を言い換えるだけの括弧は消す
   - 消す: `キャッシュ（一時的に保存したデータ）を使う`
   - 残す: `再試行は3回まで（初回を含まない）`
5. 書くことが無い見出しや行は、まるごと消す。「なし」とだけ書いて残さない
6. 読み手が初めて見る言葉を使わない
   - 助詞を抜いて名詞を詰めた語を作らず、文で書く
   - たとえを使わず、何をするかをそのまま書く
   - 1つの文で言うことは1つにする
7. 表のセルでは場合分けをしない。結果が分かれるなら行を分ける
